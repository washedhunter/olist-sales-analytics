# Sales & Customer Analytics: Olist E-Commerce

End-to-end analytics project on the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce): where revenue comes from, which customers are slipping away, how delivery performance affects ratings, and which products and regions to focus on.

**Stack:** Excel · PostgreSQL · Python · Power BI
